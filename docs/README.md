# Documentation

Bienvenido a la documentación técnica de **Habit Tracker API**.

Este directorio contiene la documentación relacionada con la arquitectura, desarrollo, base de datos y diseño de la API.

El objetivo de esta documentación es mantener registradas las decisiones técnicas, convenciones y guías necesarias para comprender, mantener y evolucionar el proyecto.

# Architecture Decision Records

Las decisiones importantes de arquitectura serán documentadas mediante ADRs.

Cada ADR incluye:

- Contexto.
- Problema.
- Alternativas consideradas.
- Decisión tomada.
- Consecuencias.

# Actualización de documentación

La documentación debe mantenerse sincronizada con la evolución del proyecto.

Cuando una nueva decisión técnica tenga impacto arquitectónico, deberá registrarse mediante un nuevo ADR o actualizarse la documentación existente.
